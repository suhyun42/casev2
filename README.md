## Publish on GitHub Pages

1. Extract the ZIP and upload its contents directly to the top level of your public GitHub repository. Keep index.html at the top level, rather than inside another folder.
2. Commit the files to main.
3. Open Settings → Pages. Choose Deploy from a branch, main, and /(root), then Save.
4. Return to Settings → Pages for the published link.

No installation or build command is required. Open index.html locally with the other files alongside it to preview. Progress is saved in each visitor’s browser.

[Official GitHub Pages instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

To update the site, replace the repository files with the latest package and commit the changes.
